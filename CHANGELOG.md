## [1.0.0] - 2025-07-29

### Added
- **Initial release** of Glassbox — the open-source time-travel debugger for multi-agent AI systems.
- **Visual execution graph** powered by React Flow, featuring real-time node streaming and status indicators.
- **Time-travel replay** engine allowing state modification and re-execution from any DAG node.
- **Planner/Worker/Aggregator agent pipeline** integrated with Groq LLM inference.
- **Interactive clarification system** enabling agent clarification questions to pause execution for human user input.
- **Dual view modes**: Simple (non-technical user view) and Developer (deep telemetry, prompt/response JSON inspector).
- **Challenge Mode & public leaderboard** for adversarial testing and community prompt engineering benchmarks.
- **Google Workspace tools**: Live integration capabilities for Docs, Sheets, Gmail, and Calendar.
- **Progressive Web App (PWA)** with offline support, service worker caching, and IndexedDB local state persistence.
